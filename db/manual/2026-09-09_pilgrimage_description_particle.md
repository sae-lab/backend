# 순례길 설명의 조사(을/를) 교정

이미 만들어진 순례길의 `description`을 한 번 손봤다. **다시 실행할 필요는 없다.**

## 왜

자동 생성 순례길 설명이 `"...를 잇는 자동 생성 구간 코스"`로 조사가 하나로
고정돼 있어서, 받침 있는 도시로 끝나면 `"횡성를 잇는"`처럼 나왔다.

코드는 `KoreanParticle.objective()`로 고쳤지만, 설명은 **생성 시점에 저장**되므로
이미 만들어진 행은 그대로였다.

## 무엇을

`description`이 `"를 잇는"`으로 끝나는 행 중, 바로 앞 도시에 받침이 있는 것만
`"을 잇는"`으로 바꿨다. 운영 DB에는 2026-09-09에 적용했다 (3건).

- `춘천 → 홍천 → 횡성를 잇는...` → `횡성을 잇는...`
- `강릉 → 동해 → 삼척를 잇는...` → `삼척을 잇는...`
- 원래 맞았던 `양구를 잇는`은 건드리지 않았다.

## 참고

SQL로 한 번에 바꾸기 어렵다. 어떤 조사를 붙일지는 앞 글자의 받침을 봐야 하는데,
그 판단을 SQL로 표현하기 번거로워 JDBC로 행을 읽어 계산한 뒤 갱신했다.
같은 일이 또 필요하면 `KoreanParticle.hasFinalConsonant()`와 같은 규칙을 쓰면 된다.
