# LAB-12 Route Planner

## 목적

사용자의 현재 위치와 가용 시간을 기반으로
산책 가능한 장소들을 조합하여 도보 경로를 생성한다.

## 입력값

- 현재 위치 좌표
- 검색 반경
- 가용 시간

## 처리 과정

1. 현재 위치 기반 관광지 후보 조회
2. 장소 간 이동 시간 계산
3. 장소별 예상 체류 시간 반영
4. 가용 시간 내 적합한 경로 생성

## 주요 컴포넌트

- Planner: 산책 경로 생성 및 장소 선택
- TravelTimeService: 장소 간 이동 시간 계산
- TourApiService: 관광지 데이터 조회
